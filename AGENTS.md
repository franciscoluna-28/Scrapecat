<!-- BEGIN:commit-conventions -->
## Commit Conventions

Use [conventional commits](https://www.conventionalcommits.org/) with lowercase types:

- `feat:` — new feature
- `fix:` — bug fix
- `refactor:` — code restructuring (no behavior change)
- `chore:` — tooling, config, dependencies
- `docs:` — documentation only

Format:
```
type: short description (imperative, lowercase, no period)

- Bullet point details when needed
- Each atomic commit should group related changes
```
<!-- END:commit-conventions -->

<!-- BEGIN:codegen-rules -->
## Codegen

- Never edit `frontend/src/shared/api/types.ts` manually. It is auto-generated by `openapi-typescript` from the backend's OpenAPI spec.
- To regenerate: run `pnpm codegen` (starts backend, generates types, stops backend).
- The backend must have `@fastify/swagger` properly configured for codegen to produce correct types.
<!-- END:codegen-rules -->
