# Code of Conduct

## Our standard

Be respectful, constructive, and professional. Harassment, discrimination, personal attacks, and abusive behavior are not tolerated.

## Scope

This code applies in all project spaces, including issues, pull requests, discussions, and reviews.

## Reporting

Report unacceptable behavior privately to the maintainer, [@franciscoluna-28](https://github.com/franciscoluna-28), or through GitHub's [report abuse](https://github.com/contact/report-abuse) form. Reports will be reviewed and handled confidentially.

Maintainers may remove, edit, or reject comments, commits, code, and other contributions that violate this code.
